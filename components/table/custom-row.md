# Пользовательская разметка строки

Свойство `custom-row-template` передаёт объект `Template` в `pl-virtual-scroll` и заменяет всю стандартную разметку строки. Ниже показаны два подхода: карточка на всю ширину и чередование группировочных строк с обычными ячейками.

## Карточка сотрудника

Каждая строка показывает имя и отдел, описание и дату приёма, оклад и премию. «Подробнее» открывает `pl-popover` с данными этой строки.

Свойство ожидает шаблон Polylib, а не строку HTML. Контекст строки доступен как `row`; шаблон передаёт его дочернему компоненту через обычный биндинг. Одна колонка задаёт общую шапку «Сотрудники Demo-company», а раскладку полей определяет карточка.

Шаблон должен подключиться до первой отрисовки данных. Инициализация свойств Polylib отложена, поэтому пример начинает с пустого массива и заполняет его в следующей задаче через `setTimeout(..., 0)`. Смена `customRowTemplate` не заменяет уже созданные строки виртуальной прокрутки.

Пользовательский шаблон заменяет стандартную строку целиком, включая её обработчики событий. Автоматическое выделение строки и события выбора таблицы в этом примере не используются. Для карточек переменной высоты включено `variable-row-height`.

## Группировочная строка и обычные ячейки

План оснащения состоит из девяти позиций в трёх рабочих зонах. Каждая зона начинается с отдельной строки на всю ширину: в ней показаны название, количество позиций и сумма. Оборудование ниже выводится через пять `pl-table-column` с общей шапкой.

Найди «Студия» или «Камера»: останутся только подходящие позиции, а суммы и состав групп пересчитаются. Выбери строку оборудования и перетащи границу заголовка колонки. Клик по заголовку группы не меняет выбранную запись.

### Подготовка данных

Исходная коллекция `records` содержит только оборудование. Отдельная коллекция `rows` предназначена для таблицы и содержит строки двух видов:

| Вид строки | Признак | Содержимое |
| --- | --- | --- |
| Заголовок группы | `isGroup: true` | Название зоны, количество найденных позиций и сумма. |
| Оборудование | `isGroup: false` | Поля исходной записи и вычисленная стоимость `quantity × price`. |

Фильтрация выполняется до добавления строки группы. Поэтому в результате нет пустых заголовков, а итог отражает именно видимые позиции. `Map` сохраняет порядок первого появления зон; внутри зоны сохраняется порядок исходных записей.

Группы и суммы собираются за один проход по `records`. Повторного поиска группы через `find` или `some` для каждой записи нет. Сборка плоского массива также линейна; исходные записи не изменяются. При пересборке выбор сохраняется по `id`, если выбранная позиция остаётся в результатах.

### Две ветки одного шаблона

`d:if` выбирает разметку по явному признаку `row.isGroup`. `d:restamp` удаляет неактивную ветку: для заголовка группы не создаются невидимые ячейки. Это важно при повторном использовании физических строк виртуальной прокруткой, когда на месте обычной записи оказывается заголовок группы или наоборот.

Обе ветки находятся внутри одного корневого `div`. Виртуальная прокрутка измеряет этот элемент для расчёта высоты: одни условные шаблоны в корне не дают ей постоянного DOM-узла для измерения.

Ветка оборудования сохраняет классы и шаблоны ячеек таблицы. Поэтому `pl-table-column` продолжает задавать поля, формат чисел, выравнивание и ширину. Обработчик выбора подключён только к обычной строке. Ресайз выполняется через стандартную шапку таблицы; собственный обработчик изменения ширины не нужен.

В этом подходе используются внутренние члены таблицы: `_columns`, `_filterCols`, `_getCellClass`, `_getRowParts`, `_getCellParts`, `_isRowActive` и `_onRowClick`. Они связывают пользовательскую строку с обычными колонками и выбором. При изменении реализации таблицы такую разметку нужно сверять с её штатным шаблоном. Множественный выбор, дерево и обработчики двойного клика в этот пример не включены.

### Стилизация и высота

Шаблон строки создаётся внутри Shadow DOM таблицы, поэтому `.group-row` и `.item-heading` оформляются через `<template is="extra styles">`. У группировочной строки собственная поверхность, а обычные строки сохраняют подсветку выбора таблицы. Подробнее — [стили собственных шаблонов](/components/table/styling).

Для разной высоты заголовков групп и оборудования включён `variable-row-height`. `growing` позволяет показать весь результат без внутренней вертикальной прокрутки. Пересборка планируется один раз на текущую серию уведомлений; при первом подключении данные поступают после установки пользовательского шаблона.
