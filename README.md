# Polylib

Polylib — библиотека для интерфейсов на Web Components. Она связывает состояние JavaScript с HTML-шаблоном: обновляет значения, повторяет элементы списка и передаёт изменения между компонентами.

Начни с устройства библиотеки и правил обновления состояния. Для разработки экранов NFJS переходи к формам и субформам; для API готового элемента — к справочнику компонентов.

## Три уровня

**Polylib** предоставляет `PlElement`, `html`, `css`, свойства, биндинги и директивы шаблонов. Эти возможности работают в браузере без NFJS.

**Компоненты `@plcmp/*`** — отдельные npm-пакеты с готовыми элементами управления. Они предоставляют поля ввода, кнопки и контейнеры раскладки.

**NFJS `@nfjs/front-pl`** добавляет `PlForm`, загрузчик форм, навигацию, субформы, `pl-dataset` и `pl-action`. Эти механизмы требуют окружения приложения NFJS.
