# Шаблоны и директивы

Шаблон создаётся через `html` и разбирается Polylib при объявлении. При подключении элемента он клонируется, биндинги прикрепляются к контексту, затем DOM вставляется в корень элемента. В обычном `PlElement` корень — открытый Shadow DOM.

```js
import { html, PlElement } from 'polylib';

class PlPanel extends PlElement {
  static properties = { caption: { type: String, value: '' } };
  static template = html`<section><slot></slot><p>[[caption]]</p></section>`;
}
```

## Условный DOM: `d:if`

`d:if` управляет поддеревом шаблона. По умолчанию при false узлы скрываются, сохраняя DOM и состояние вложенных компонентов. При следующем true они показываются повторно.

```html
<template d:if="[[showDetails]]">
  <pl-input value="{{details}}"></pl-input>
</template>
```

`d:restamp` без значения включает удаление поддерева при false. При следующем true Polylib создаёт его заново. Это важно для компонентов с локальным состоянием: при обычном `d:if` введённое значение остаётся, при restamp DOM и локальное состояние теряются.

**Правильно: сохранить созданное поддерево при временном скрытии**

```html
<template d:if="[[showDetails]]">...</template>
```

**Правильно: удалить поддерево, когда требуется пересоздание**

```html
<template d:if="[[showDetails]]" d:restamp>...</template>
```

Не добавляй `d:restamp` просто для условного отображения. Добавляй его, когда повторное создание поддерева — нужная часть поведения.

## Повтор: `d:repeat`

Повтор ожидает коллекцию и создаёт клон вложенного шаблона для каждого элемента. Без `d:as` имя текущей записи — `item`; с атрибутом `d:as` используется заданный alias.

```html
<template d:repeat="[[rows]]" d:as="row">
  <button on-click="[[selectRow]]">[[row.title]]</button>
</template>
```

Для добавления и удаления строк используй `push` и `splice`, иначе Polylib не получит уведомление об изменении массива. Передача нового массива через свойство тоже обновляет repeat.

```js
selectRow(event) {
  this.set('selectedTitle', event.model.row.title);
}
```

`event.model` формируется обработчиком Polylib и содержит alias каждого окружающего repeat; детали — в [событиях](/guide/events). Вложенные повторы добавляют несколько именованных моделей.

### Редактируемые строки

Если поля внутри повтора меняют запись, двусторонняя связь нужна и на самом `d:repeat`. Так уведомление проходит из поля через контекст строки к родительской коллекции.

**Правильно: вернуть изменения строки в родительский контекст**

```html
<template d:repeat="{{rows}}" d:as="row">
  <pl-input value="{{row.title}}"></pl-input>
</template>
```

**Неправильно: оставить односторонний repeat для редактирования общей модели**

```html
<template d:repeat="[[rows]]" d:as="row">
  <pl-input value="{{row.title}}"></pl-input>
</template>
```

Во втором случае общий объект может измениться, но уведомление не вернётся в родительский контекст. Внешний observer и связанные части экрана не узнают о правке. Работающий пример — [pl-data-observer](/components/pl-data-observer).

Это тот же механизм общей ссылки, что и при [передаче объекта дочернему компоненту](/guide/object-bindings). При замене или перестановке массива учитывай ещё одно свойство: [экземпляры строк переиспользуются по позиции](/guide/edge-cases?id=drepeat-сохраняет-экземпляры-по-позиции), а не по `id` записи.

<div class="demo"><pl-doc-template-demo></pl-doc-template-demo></div>
<p class="demo-status" role="status">Загружаем примеры…</p>

[Полный код работающего примера](../demos/templates.js ':include :type=code javascript')

Введи текст в оба поля, затем скрой и покажи их флажком. Первое поле сохранит введённое, второе создастся заново. Кнопки списка выбирают строку через `event.model.row`.

## Слоты

Слот принимает разметку, которую передаёт родитель. Состояние этой разметки продолжает принадлежать контексту, где она объявлена.

Шаблон собственного элемента `pl-panel`:

```html
<header><slot name="header"></slot></header>
<section><slot></slot></section>
```

Использование в шаблоне родителя:

```html
<pl-panel>
  <h2 slot="header">[[title]]</h2>
  <p>[[description]]</p>
</pl-panel>
```

`title` и `description` читаются из родителя. Вложенный элемент определяет места вставки содержимого. Для передачи данных самой панели объяви её свойства и используй биндинги на теге `pl-panel`.

## Где выполняется шаблон

Синтаксис `[[...]]`, `{{...}}` и `d:*` обрабатывается внутри `html`-шаблона Polylib. Эти записи в обычном HTML страницы сами по себе не создают контекст и не становятся реактивными.

Динамические значения передавай через биндинги, без JavaScript-интерполяции `${...}` в `html`. Вычисления выполняй в методах с явно перечисленными зависимостями.

## Ограничения

* Директивы ядра в Polylib — `d:if` и `d:repeat`; они регистрируются при импорте пакета.
* `d:if` скрывает элементы через `display: none`, сохраняя уже созданные узлы; `d:restamp` влияет на удаление.
* При обработке изменений массива для repeat используй методы контекста. Детали реактивных коллекций — [реактивность](/guide/reactivity).
