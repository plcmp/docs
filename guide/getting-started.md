# Первый компонент

Компонент Polylib — ES-модуль с классом, шаблоном и объявленными свойствами. В первом примере кнопка увеличивает счётчик, а биндинг выводит его значение.

## Подключение библиотеки

В модуле компонента импортируй базовый класс, функцию шаблона и функцию стилей:

```js
import { PlElement, html, css } from 'polylib';
```

## Собственное состояние и шаблон

В этом примере обычная HTML-кнопка показывает, как ядро обрабатывает браузерные события без зависимости от набора `@plcmp/*`.

<div class="demo"><pl-doc-counter></pl-doc-counter></div>
<p class="demo-status" role="status">Загружаем примеры…</p>

[Код примера](../demos/counter.js ':include :type=code javascript')

`static properties` объявляет реактивное состояние. `static template` описывает DOM. `static css` оформляет внутренние элементы. `customElements.define` регистрирует класс под HTML-тегом один раз.

Клик вызывает `increment` в контексте экземпляра. Присваивание `this.count` уведомляет библиотеку, и `[[count]]` получает новое значение. Ручного изменения `textContent` здесь не требуется.

Сохрани компонент в `pl-doc-counter.js`. Импортируй его в модуле, где он используется:

```js
import './pl-doc-counter.js';
```

После импорта тег доступен в шаблоне:

```html
<pl-doc-counter></pl-doc-counter>
```

## Подключение готовых элементов

Готовые компоненты устанавливаются отдельными пакетами:

```bash
npm install polylib @plcmp/pl-button
```

```js
import { PlElement, html, css } from 'polylib';
import '@plcmp/pl-button';
```

Импорт пакета регистрирует его HTML-тег. После импорта `@plcmp/pl-button` используй `<pl-button>` в шаблоне компонента.
