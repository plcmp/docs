# Стили и Shadow DOM

По умолчанию `PlElement` создаёт открытый Shadow DOM. Шаблон и стили компонента изолированы от обычных селекторов страницы; глобальные стили документа также не проникают внутрь Shadow DOM.

Стили задаются через `static css` и присоединяются к корню компонента при подключении:

```js
import { css, html, PlElement } from 'polylib';

class PlStatusBadge extends PlElement {
  static properties = { label: { type: String, value: '' } };

  static css = css`
    :host {
      display: inline-flex;
      align-items: center;
    }
  `;

  static template = html`<span>[[label]]</span>`;
}
```

`:host` выбирает сам пользовательский элемент. Применяй его для задания `display`, размеров и других свойств компонента.

**Правильно: обратиться к корню элемента через `:host`**

```css
:host { display: block; }
```

**Неправильно: ожидать, что селектор документа попадёт внутрь Shadow DOM**

```css
body .status-badge span { color: red; }
```

Второй селектор работает только там, где нет границы Shadow DOM. Для оформления содержимого задавай классы и селекторы в CSS самого компонента.

## CSS-переменные и тема

CSS-переменные наследуются через границу Shadow DOM. Поэтому переменная, заданная приложением на предке или самом пользовательском элементе, может использоваться внутри компонента:

```css
:host {
  color: var(--component-text-color, currentColor);
  padding: var(--component-padding, 0.5rem);
}
```

Компоненты `@plcmp/*` используют переменные `--pl-*`. Сам Polylib предоставляет механизм CSS и Shadow DOM; названия и значения переменных задаёт библиотека компонентов или приложение.

**Правильно: использовать переменную темы компонента**

```css
:host { color: var(--pl-text-color); }
```

**Неправильно: зафиксировать цвет, который должен меняться с темой**

```css
:host { color: #293142; }
```

Второй вариант жёстко связывает компонент с одним цветом и мешает теме приложения. Для своего компонента можно определить отдельные CSS-переменные с понятным назначением.

## Открытые части: `::part`

Компонент может разрешить оформление отдельных внутренних узлов через атрибут `part`. Например, в шаблоне своего компонента:

```html
<span part="label">[[label]]</span>
```

Если этот шаблон принадлежит `pl-status-badge`, владелец элемента может оформить подпись из своей области стилей:

```css
pl-status-badge::part(label) {
  font-weight: 600;
  color: var(--pl-primary-base);
}
```

Правило размещается там, где доступен сам `pl-status-badge`: в CSS страницы для элемента на странице или в `static css` родительского компонента для элемента внутри его шаблона. Обычный селектор страницы не проходит через Shadow DOM родителя даже при наличии `::part`.

Часть должна быть явно объявлена компонентом. Имя класса, `id` или имя слота само по себе не создаёт `part`. Доступные части и примеры их применения перечислены в разделе «Стилизация» каждого компонента.

### Части вложенного компонента

Через несколько границ Shadow DOM часть нужно передать наружу с помощью `exportparts`. Например, компонент-обёртка может открыть части своего поля:

```html
<pl-input exportparts="label,input-container,native-input"></pl-input>
```

Тогда внешний владелец обращается к этим частям через тег обёртки. Само наличие `part` во вложенном `pl-input` без `exportparts` такого доступа не даёт.

CSS-переменные подходят для общей темы и наследуются вложенными элементами. `::part` меняет конкретный открытый узел. Собственные классы шаблона оформляй в той области DOM, где создаётся разметка; для шаблонов таблицы предусмотрен отдельный механизм [extra styles](/components/table/styling).

## Атрибуты и состояния

Селекторы атрибутов подходят для состояния, отражаемого в атрибут. `reflectToAttribute` на свойстве включает синхронизацию свойства с атрибутом; обычный `hidden` атрибут имеет стандартную семантику HTML.

```css
:host([disabled]) { opacity: 0.6; }
```

Разница между свойством и атрибутом — в [биндингах](/guide/bindings).

## Ограничения

* Поле `static css` принимает Polylib CSS-шаблон или `CSSStyleSheet`; для `CSSStyleSheet` браузер должен поддерживать `adoptedStyleSheets`.

* В Shadow DOM селекторы страницы не стилизуют внутренние узлы напрямую.

* `:host` относится к Shadow DOM; `PlElement` можно создать с настройкой light DOM, и тогда изоляции нет.
