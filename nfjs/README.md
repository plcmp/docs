# NFJS

NFJS — модульная платформа для приложений с данными: справочников, реестров, учётных систем и рабочих мест пользователей. Она связывает сервер на Node.js, PostgreSQL и браузерные формы. Разработчик описывает модель данных, операции над ней и интерфейс, а модули платформы предоставляют загрузку приложения, HTTP, сессии, доступ к базе, права, формы и инструменты разработки.

Типичный экран NFJS — реестр с фильтрами и карточка записи. За экраном стоят запрос чтения, зарегистрированные операции добавления и изменения, ограничения базы и права пользователя. Такой подход позволяет использовать одну модель и правила записи в нескольких формах и API.

## Какие задачи решает платформа

| Задача | Средства NFJS |
| --- | --- |
| Разделить приложение на функциональные модули | npm-пакеты, `nf-module.js`, зависимости и порядок инициализации |
| Предоставить данные форме или внешнему клиенту | HTTP-маршруты, `dbapi`, `serverEndpoints` |
| Сохранить несколько связанных записей | Соединение с транзакцией и операции `broker` |
| Учесть текущего пользователя и его права | Сессия, контекст провайдера, разделы и операции DBFW |
| Собрать реестр, карточку и вложенные формы | `PlForm`, Polylib и компоненты PLCMP |
| Перенести структуру базы между окружениями | Исходники `dbsrc` и `@nfjs/migrate` |
| Ускорить создание стандартных экранов | Редактор БД, метаданные разделов и генератор `@nfjs/dev` |

NFJS подходит для приложений, в которых много форм, связей между сущностями и повторяющихся операций с данными. Состав приложения выбирается по задаче: подключаются необходимые пакеты и прикладные модули.

## Как устроено приложение

**Браузер.** Форма наследуется от `PlForm`. Polylib связывает свойства формы с шаблоном, а PLCMP предоставляет поля, кнопки, таблицы и другие элементы. `pl-dataset` загружает коллекции, `pl-action` выполняет операции. Родительская форма управляет данными и сохранением, вложенные формы редактируют переданные им части состояния.

**Сервер.** `@nfjs/core` загружает конфигурацию и модули. `@nfjs/back` предоставляет HTTP и API провайдеров данных. В обработчик запроса приходит контекст с параметрами и сессией. Через него операция получает соединение от имени нужного пользователя приложения.

**База данных.** PostgreSQL хранит данные, связи и ограничения. В стеке с DBFW разделы регистрируются в `nfc.unitlist`, операции — в `nfc.unitbps`. Запись выполняется через `broker`: он находит контракт операции, проверяет права и выполняет изменение в транзакции. Представления чтения возвращают данные, доступные пользователю.

**Инструменты.** Редактор БД помогает создавать и изменять объекты PostgreSQL. Генератор строит начальную разметку форм по метаданным таблицы и выбранному шаблону. Исходники объектов и настроек сохраняются в модуле, чтобы изменения можно было повторить в другой базе.

## NFJS, Polylib и PLCMP

| Часть | За что отвечает |
| --- | --- |
| **Polylib** | Реактивные свойства, биндинги, события, шаблоны и базовый `PlElement` |
| **PLCMP** | Готовые пользовательские элементы: поля ввода, таблицы, вкладки, всплывающие панели |
| **NFJS** | Запуск приложения, сервер и база, загрузка форм, навигация, сессия и прикладные операции |

Polylib и компоненты можно использовать самостоятельно. NFJS добавляет окружение приложения: например, `this.open()` для открытия формы, загрузчик классов форм и серверное выполнение `pl-action`.

## Два способа связать форму с сервером

**REST-маршрут** регистрируется в `nf-module.js`, а обработчик живёт в backend-модуле. Он получает `context`, выполняет запросы или операции и отправляет ответ. Подход удобен для самостоятельного API, нескольких клиентов и сценариев с прикладной оркестрацией.

**`serverEndpoints`** описывает запросы и действия в классе формы. Загрузчик NFJS извлекает этот блок на сервере; в браузер уходит клиентская часть класса. Компоненты обращаются к действиям по имени формы и своему `id`. Подход удобен для запросов и декларативных операций конкретной формы.

Оба способа используют провайдеры NFJS и одни и те же контракты записи. Выбор способа не меняет необходимость транзакции и проверки прав в операции записи.
